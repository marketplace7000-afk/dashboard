## Что передается

- **Код** - GitHub `romanov-d/avtovibe`, ветка `main`. Рабочая копия на сервере в `/opt/autovibe` идентична (выкатка - rsync, не git).
- **Сервер** - VPS Timeweb `200.165.234.229`, домен `e-avtovibe.ru`. Там же: `.env` с секретами, кэш `.av-cache/`, введенные руками данные `av-data/`.
- **Vercel-проект** `aimarket` - только релеи Anthropic и Telegram.
- **Доступы** - по чек-листу в разделе 3.5.
- **Клиентские вещи, которые остаются у клиента**: кабинеты WB/Ozon (токены), аккаунт Anthropic (баланс), Google-таблица «Склад (orig)», бот в BotFather.

## Что еще есть в репозитории

- `docs/МАТЕМАТИКА.md`, `docs/КАЛЬКУЛЯТОРЫ_КЛИЕНТА_ЛОГИКА.md` - формулы прибыли, ROI, прогноза закупок: как считает клиент и как повторено в коде.
- `docs/ОТЧЕТ_ОГРАНИЧЕНИЯ_API.md` - что площадки не отдают по API и почему часть цифр недостижима.
- `docs/ПРАВКИ_КЛИЕНТА_2026-07-03.md`, `docs/ПРАВКИ_ТЕЛЕМОСТ_2026-08-11.md` - замечания клиента по итогам созвонов и что по ним сделано.
- `docs/COMPETITOR_PARSER.md` - как устроен сбор данных о конкурентах. `docs/supply_tracker.gs` - Apps Script, который стоит в таблице клиента.
- `deploy/` - юнит systemd, nginx, провижининг, шаблон `.env`.
- `scripts/` - проверки `npm run check` и `smoke.sh`.
