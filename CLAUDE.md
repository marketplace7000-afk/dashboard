# Правила разработки кабинета e-avtovibe.ru

Правила выведены из аварий и общей проверки 12.11.2026. Они обязательны для любого нового раздела и любой правки.
Перед выкладкой всегда: `npm run check` и `npm run build` — оба без ошибок. Выкладка — только после «да» владельца.

## 1. Ошибки

- Сбой одного источника не роняет раздел: остальные цифры показываем, а сбой называем на экране словами («не прочитан план месяца»), а не прячем. Образец — `allAdvice()` в `api/_lib/cardAdvice.ts` (список `failed`).
- Пустой `catch {}` запрещён. Либо `console.warn('[модуль] что не удалось:', причина)`, либо `noteSwallowed()` из `api/_lib/log.ts`.
- Под systemd в журнал попадает только `console.warn` / `console.error`; `console.log` буферизуется и не виден.
- Пустой или частичный ответ площадки не затирает прошлые хорошие данные (кэш, слепки, РНП).
- Сообщение «ошибка» в журнале должно означать настоящую ошибку. Ложные тревоги чинить, а не привыкать к ним.
- На каждую новую формулу или правило — проверка в `scripts/check-*.ts`, подключённая в `npm run check`.
- Экран целиком защищён `ErrorBoundary`; новый раздел подключать внутри него.

## 2. Запросы к WB и Ozon

- В площадки ходим только через `fetchWithRetry` (`api/_lib/fetchRetry.ts`): он ставит запрос в общую очередь `gateway.ts`. Голый `fetch` к WB/Ozon запрещён. Для действий без автоповтора (одобрить заявку, сменить ставку) — `gate()` + `note()` вокруг `fetch`.
- Новый метод с жёстким лимитом — новое правило в `RULES` в `gateway.ts` с интервалом из документации площадки.
- Лимиты WB считаются на весь кабинет, а не на ключ. У Ozon общий бюджет около 50 запросов в секунду на кабинет (заголовок `ratelimit-remaining`); его делят сайт, Baloo и боты.
- После 429 пауза растёт с каждой попыткой. Не повторять запрос чаще, чем просит площадка; при долгом штрафе — отложить до следующего прохода (cooldown), а не долбить.
- После длинной постраничной выгрузки Ozon давать паузу перед следующей серией (см. `logisticsFact.ts`).
- Фоновая задача берёт приоритет 2 (история) или 1 (свежие данные); приоритет 0 — только действие человека или автопилота.

## 3. Фоновые задачи и агенты

- Тяжёлые сборы идут одной цепочкой в `api/_lib/cron.ts` (warm-extras), по очереди, а не параллельно. Новый сбор добавлять в конец цепочки со своим порогом свежести («сам решает, пора ли»).
- У каждой задачи защита от повторного входа (флаг «уже идёт»).
- Свой таймер заводить только для того, что нельзя ждать 2 часа (чаты, заявки на скидку). Таймер регистрировать в `server.ts` с комментарием, как часто и зачем.
- Агент на ПК выполняет одно задание за раз (один браузер, один IP). Новые расписания разносить по минутам с соседними; антибот площадок не обходить.

## 4. Связи между разделами

- Одна цифра — один источник. Цена и маржа — из расчёта «Цен» (`margin.ts`), заказы и реклама — из РНП (`rnp.ts`), конкуренты — из `ads/cabinet.ts` и `competitorWatch.ts`, план месяца — из `plan.ts`. Не считать то же самое второй раз по-своему.
- Совет (карточка, реклама, цена) обязан учитывать: маржу и её минимум, цену против рынка конкурентов, рекламу и её запас, остаток, план месяца. Новое правило совета добавлять в `cardAdvice.ts` / `ads/signals.ts`, а не на экране.
- ИИ-чат получает готовые сигналы советника и советы по карточкам (`aiHandlers.ts`); новый источник выводов добавлять туда же.
- Ставки конкурентов площадки не отдают: есть только оценка их рекламного расхода и «Сравнение карточек» WB. Не выдавать оценку за факт.

## 5. Дизайн

- Один шрифт на весь кабинет — Golos Text (задан на `body`); в разделах только `font-family: inherit`. Моноширинный — лишь для кодов и ключей.
- Текст не мельче 15 px; основной 17–19 px. Размеры брать из переменных `--sa-small / --sa-cap / --sa-body / --sa-em / --sa-h2`. Следит `scripts/check-design.ts`.
- Проверять на ширине окна владельца: около 1385 px (окно 1150 px при масштабе 83 %) и на телефоне.
- Широкая таблица живёт в блоке с горизонтальной прокруткой (`.rnp-scroll`, `.ad2-scroll`) или перестраивается по `@media`; страница целиком вбок не прокручивается.
- Ячейки сетки: `min-width: 0; overflow-wrap: anywhere`, чтобы длинный артикул не вылезал из рамки. Числа — `font-variant-numeric: tabular-nums`.
- Тексты интерфейса — по-русски, простыми словами, без технических терминов.

## 6. Перед тем как сказать «готово»

- `npm run check`, `npm run build`.
- Новый экран открыт в браузере на ширине 1385 px: ничего не обрезано и не вылезает.
- Цифры нового раздела сверены с кабинетом площадки или прямым ответом API хотя бы за один день.
