## 8.2 Грабли, на которые не наступать

- **`rsync -a` от root** ломает права: uid 501 с ноутбука → сервис теряет запись в `.av-cache` и `av-data`, и это не видно неделями. Только `-rlptz` + `chown`.
- **Пустой `catch`** запрещен: либо в журнал через `noteSwallowed`, либо наверх. Один такой прятал поломку месяц.
- **Ключ кэша = тело запроса.** Тела и окна дат - только из `api/_lib/period.ts` / `src/utils/period.ts`. Своя копия в любом модуле = промах и пустой экран без ошибок. `npm run check` это ловит.
- **Файлы в `api/` - отдельные функции Vercel.** Общий код кладется в `api/_lib/` (префикс с подчеркиванием не случаен).
- **Один активный отчет у Ozon Performance.** Никогда не «заказывать заново вместо дождаться» - UUID запоминается и подбирается.
- **Поле `nms`, не `nm`** в статистике рекламы WB.
- **Vercel нельзя ставить на паузу** - там релеи Anthropic и Telegram.
- **Колонки таблицы клиента двигаются.** Парсер ищет по заголовкам (`SKU…`, `Закуп`), вкладку - по списку листов. Не возвращать номера колонок.
- **VPN Happ на ноутбуке** перехватывает SSH/HTTP к серверу; fail2ban банит параллельные заходы (в том числе несколько ИИ-агентов разом).
- **`AUTH_PASSWORD` пустой = кабинет открыт без пароля.** Так было до 10.08.2026.
- **`vite dev`** ходит в площадки напрямую с ноутбука - WB с не-российского адреса отдает 403, а лимиты - на весь кабинет. Для проверки использовать `npm run serve`.

## 8.3 Технический бэклог (без клиента)

1. **Перенести релеи** Anthropic и Telegram с Vercel на любой не-РФ хост (маленькая функция), после чего Vercel можно выключить - он жжет ~43 GB-часа в месяц впустую.
2. **Российский выход для `card.wb.ru`** - витрина WB и конкуренты.
3. **Закрепить DNS на сервере** - после перезагрузки маршруты возвращаются из DHCP.
4. Дорезать `api/route.ts` (осталось ~700 строк, самодостаточные секции).
5. Убрать устаревшее: `vite.config.ts` dev-прокси, `VITE_WB_TOKEN*`/`VITE_TELEGRAM_*` (токен уходит в бандл), ветку `KV_REST_API_*` в `cache.ts`, корневой `.env.example` (описывает Vercel-эпоху).
6. Дубль строки `TELEGRAM_BOT_TOKEN` в `/opt/autovibe/.env`.
7. `deploy/env.server.example` не содержит ~30 переменных, которые есть в коде (список - раздел 5, «Расхождения шаблона и кода»); критичны `ANTHROPIC_PROXY_URL`, `RELAY_SECRET`, `GOOGLE_SA_KEY_FILE`, `SKLAD_SHEET_ID`.
