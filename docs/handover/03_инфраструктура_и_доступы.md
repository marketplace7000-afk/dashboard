## 3.2 Как зайти

```bash
ssh root@200.165.234.229
```

Вход по ключу ed25519, пароля нет. Ключ нужно передать новому разработчику отдельно (или добавить его публичный ключ в `/root/.ssh/authorized_keys`).

Две известные ловушки:

- **VPN на ноутбуке.** Happ (sing-box в режиме TUN) перехватывает весь трафик: SSH рвется на banner/kex, HTTP отдает пустой ответ, а `nc -vz 1.1.1.1 9` отвечает «succeeded» на закрытый порт. Перед заходом VPN выключить. Это стоило целого дня в сентябре 2026.
- **fail2ban.** Частые заходы банят IP на 10-15 минут. Стучаться из одного места, не запускать несколько параллельных SSH-сессий (в том числе из нескольких агентов). Сайт при этом жив: `curl -s -o /dev/null -w "%{http_code}" https://e-avtovibe.ru` → 200.

## 3.3 Где лежат секреты

Ни одного секрета нет в git и не должно быть. Все на сервере в **`/opt/autovibe/.env`**, шаблон с описанием - `deploy/env.server.example`. Полный справочник переменных - раздел 5.

| Группа | Кто выдает | Где взять новое |
|---|---|---|
| `WB_TOKEN` | клиент, кабинет WB Seller → Настройки → Доступ к API | клиент. Нужны права на все разделы, включая **Финансы** (без них 403 у финотчета и штрафов) |
| `OZON_CLIENT_ID`, `OZON_API_KEY` | клиент, Ozon Seller → Настройки → API-ключи | клиент. Ozon деактивирует ключи; 01.09.2026 пришлось менять |
| `OZON_PERF_CLIENT_ID`, `OZON_PERF_CLIENT_SECRET` | клиент, Ozon Performance → API | клиент |
| `ANTHROPIC_API_KEY` | console.anthropic.com | аккаунт клиента; баланс пополняет клиент |
| `TELEGRAM_BOT_TOKEN` | @BotFather | бот `@Podsort_FF_bot`; при смене - перевыпустить у BotFather |
| `GOOGLE_SA_KEY_FILE` | Google Cloud, сервисный аккаунт `avtovibe-sheets@atoms-press.iam.gserviceaccount.com` | JSON-ключ лежит в `/opt/autovibe/av-data/google-sa.json`; клиент должен поделиться таблицей «Склад» с этим адресом |
| `AUTH_PASSWORD`, `AUTH_SECRET`, `CRON_SECRET`, `RELAY_SECRET` | придумываются нами | `RELAY_SECRET` должен совпадать на сервере и в Vercel |

**Правило:** секреты в файлы вписывает человек руками, в переписку и в документы они не попадают. Готовый скрипт для безопасного ввода - `/root/set-keys.sh` на сервере (значения не показываются и не попадают в историю shell).

Что засветилось и требует ротации - раздел 8.
