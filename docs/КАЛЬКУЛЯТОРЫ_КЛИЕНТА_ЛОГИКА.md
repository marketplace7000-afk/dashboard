# Логика калькуляторов клиента (эталон для нашего модуля «Цены»)

Источники (готовые калькуляторы клиента):
- Ozon: https://calcul-ozon.netlify.app
- WB:   https://kalkulyator-wb-rus.netlify.app

Формулы вытащены из инлайн-JS этих страниц (функция `calculate()` / `calc()`).
Это **эталон**: переносим 1-в-1 в наш калькулятор WB FBW.

---

## Ключевой вывод (важно для всей переделки)

1. **СПП / цена покупателя — это РУЧНОЙ ВВОД (ползунок `spp`), НЕ живьём.**
   Она используется только: (а) как база налога, (б) для отображения «цена покупателя».
   **В расчёте прибыли участвует цена продавца (ценник/РРЦ), а не цена покупателя.**
2. **Комиссия, эквайринг, реклама — считаются от ЦЕНЫ ПРОДАВЦА (retailPrice / price),
   не от цены со скидкой.** Совпадает с тем, что отдаёт API (продавец получает свою цену,
   соинвест финансирует площадка).
3. Значит для честной прибыли реальная витринная СПП НЕ нужна — нужны только
   комиссия %, тарифы логистики/хранения, налог %, ДРР %. Всё это есть по API
   (Ozon `v5/product/info/prices.commissions`; WB `tariffs/commission` + `tariffs/box`).

---

## OZON — формула прибыли

Входы: `price` (цена продавца), `spp%`, `commission%` (по категории/цене), `acquiring%`,
`ads%` (ДРР), логистика `logistic` (₽), `returns%`, `storage` (₽), налоги.
Себестоимостные слагаемые: `costChina + logChina + delivery + deliveryOzon + fulfillment + package + other`.

```js
cogsRaw    = costChina + logChina + delivery + deliveryOzon + fulfillment + package + other
commR      = price * commPct           // комиссия — от цены продавца
retR       = logistic * retPct         // обратная логистика = прямая × % возвратов
logTotal   = logistic + retR
acqR       = price * acqPct            // эквайринг
adsR       = price * adsPct            // реклама (ДРР)
buyerPrice = price * (1 - sppPct)      // цена покупателя (для налога и показа)
// Налог:
//   УСН = buyerPrice * usnPct          (начисляется сверху от цены покупателя)
//   НДС = (buyerPrice - УСН) * ndsPct/(1+ndsPct)   (выделяется изнутри)
totalCosts = cogsRaw + commR + logTotal + acqR + adsR + storage + tax
profit     = price - totalCosts
margin     = profit / price
roi        = profit / cogsRaw
```

Рейтинг маржи: ≥20% 🟢 отлично · 15–19% 🟡 хорошо · 10–14% 🟠 плохо · <10% 🔴 в ноль.

## WB (FBW) — формула прибыли

Входы: `retailPrice` (ценник/цена продавца), `spp%`, `commissionFBW%`, `buyout%` (выкуп),
`ads%` (ДРР), `il` (индекс локализации), тарифы логистики/хранения, налоги.
Себестоимость: `totalCostFull = costPrice + logChina + logUfa + packaging`.

```js
sppPrice          = retailPrice * (1 - spp/100)          // цена с СПП (для налога/показа)
commission        = retailPrice * commPct/100            // комиссия — от ценника
acquiring         = retailPrice * 0.025                  // эквайринг 2.5%
logisticsCost     = (log1 + logD * volExtra) * il        // логистика × индекс локализации
storageCost       = (stor1 + stor1 * volExtra) * storageDays
// Возврат при невыкупе, размазан на 1 выкупленный товар:
returnLogBase     = autoReturn ? (defectR1 + defectRd*volExtra) : (46 + 14*volExtra)
returnCostPerSale = returnLogBase * (1 - buyout/100) / (buyout/100)
defectCostPerSale = (defectR1 + defectRd*volExtra) * defectRate/100
usn               = sppPrice * 0.01                      // УСН 1% от цены с СПП
nds               = (sppPrice - usn) * 0.05              // НДС 5%
adsCost           = retailPrice * adsPct/100

totalCosts = totalCostFull + commission + acquiring + logisticsCost + storageCost
           + returnCostPerSale + defectCostPerSale + (usn+nds) + adsCost
           + acceptance + delivToWb + other
profit     = retailPrice - totalCosts
marginPct  = profit / retailPrice * 100

// Что WB перечисляет продавцу:
revenueFromWB = sppPrice - commission - acquiring - logisticsCost
```

Примечания WB:
- Формула логистики действует с 13.07.2026, ИРП отключён (только индекс локализации `il`).
- Возврат при невыкупе размазывается на выкупленные: `× (1-выкуп)/выкуп`.
- Автовозврат: невыкуп едет на склад WB (46₽+14₽/л) либо в ПВЗ по тарифу склада (201–360₽).

## Что берём по API (замена таблицы)

| Данные | Ozon | WB |
|---|---|---|
| Комиссия % | `v5/product/info/prices` → `commissions.sales_percent_fbo/fbs` | `/api/v1/tariffs/commission` |
| Логистика ₽ | `commissions.fbo_*`/`fbs_*` (доставка, магистраль, обр. поток) | `/api/v1/tariffs/box` |
| Цена продавца | `price.marketing_seller_price` / `price.price` | `discounts-prices` / из продаж |
| Факт. ДРР | Ozon Performance API | WB adv fullstats |
| Себестоимость | — (данные клиента, из таблицы) | — (из таблицы) |
| СПП % | ручной ввод (витринную цену API не отдаёт) | из продаж `finishedPrice` (реальная) |
