# Данные кабинетов WB и Ozon для Агента 3 (разведка 14.10.2026)

Снято в Chrome агента (профиль со входом владельца), только чтение. Запросы делает сама страница
кабинета с cookie сессии; сценарии агента повторяют их через `page.evaluate(fetch…)` изнутри открытой
страницы кабинета — как `ozon_reviews`. Строку с функцией передавать в evaluate строкой (tsx `__name`).

## WB — seller.wildberries.ru (подписка «Джем Продвинутый»)
Хост данных: `https://seller-content.wildberries.ru/ns/analytics-api/content-analytics/api/…`

| Раздел (адрес страницы) | Запрос | Что даёт |
|---|---|---|
| Воронка продаж `/content-analytics/interactive-report/main` | POST `v1/sales-funnel/report` `{currentPeriod:{start,end}, prevPeriod, subjects:[], brands:[], nms:[], tagIds:[], skipDeletedNm:false, orderBy:{field:"orders",mode:"desc"}}` | наша воронка по дням: показы, переходы, корзины, заказы, выкупы, конверсии + прошлый период |
| Поисковые запросы: ваши товары `/search-analytics/my-search-queries` | POST `v3/search-report/report` `{currentPeriod, pastPeriod, nmIds:[], subjectIds:[], brandNames:[], tagIds:[], orderBy:{field:"openCard",mode:"desc"}, positionCluster:"all", includeSubstitutedSKUs:true, includeSearchTexts:true}` | средняя/медианная позиция в поиске по дням, видимость, группы товаров с запросами |
| то же | POST `v2/search-report/table/recommendations` `{currentPeriod, nmIDs:[…]}` | по каждому nm: что мешает ранжированию (конверсия, логистика, акция, фото, рейтинг…) good/bad |
| Поисковые запросы на WB `/search-analytics/popular-search-queries/main` | POST `v1/search-analysis/premium/search-texts` `{limit,offset,subjectIDs,itemIDs,searchText,interval:"yesterday",orderBy:{field:"frequency"}}` | частота запросов по рынку, переходы/корзины/заказы, число карточек |
| Анализ ниш `/platform-analytics/niche-analysis/main` | POST `v1/market-niche/reports/premium/main-table` `{interval:"week",subjectIDs,itemIDs,…,limit,offset}` | ниши: выручка, средняя цена, продавцы, монополизация, оборачиваемость |
| Сравнение карточек `/platform-analytics/cards-comparison` | POST `v1/competitor-comparison/history` `{orderBy:{field:"date",mode:"desc"},limit,offset}`; GET `v1/competitor-comparison/limits` | наборы «наш товар + 4 конкурента», созданные менеджерами; лимит: `availableWithoutCharge` (бесплатно открыть), `remainingComparisonsThisMonth` |
| то же, отчёт | POST `v4/competitor-comparison/nms` (и `nms/detail`, `nms/search-queries`) `{nmIDs:[…], startDate, endDate, searchQueriesOrderBy:{field,mode,nmID}, officesAndRegionsOrderBy, sizeDetails:false}` | по каждому nm по дням: показы, переходы, корзины, заказы, сумма, выкупы, **средняя позиция**, CTR, **медианная цена**; по запросам — позиции и заказы конкурентов |

ВНИМАНИЕ: открыть сравнение не из `availableWithoutCharge` = списать 1 сравнение из месячного лимита
(«Можно открыть за 1 сравнение»). Без решения владельца агент открывает только бесплатные наборы.
14.10 при пробном нажатии по тексту меню кабинет отметил уведомления прочитанными — в сценариях
никаких кликов, только переход по адресу и запросы чтения.

## Ozon — seller.ozon.ru (Premium Plus)
| Раздел | Запрос | Что даёт |
|---|---|---|
| Товары на Ozon `/app/analytics/what-to-sell/ozon-bestsellers` | POST `https://api.seller.ozon.ru/api/site/seller-analytics/what_to_sell/data/v3` `{limit:"50",offset:"0",filter:{stock:"any_stock",period:"weekly",categories:[id3…]},sort:{key:"sum_gmv_desc"}}` | товары рынка в категории: продавец, цена, выручка, заказы, сессии, конверсии в корзину (поиск/карточка), **ДРР**, дни в акциях/трафаретах, доступность; `benchmark` — медиана категории |
| Конкурентная позиция `/app/analytics/what-to-sell/competitive-position` | POST `/api/site/analytics-competitive-pos/analytics/competitive_position` `{date_from,date_to,filter:{category:{level:"2",id}},group_by:"day",metric:"revenue"}` | наше место среди продавцов категории по дням |
| Поисковые запросы `/app/analytics/what-to-sell/all-queries` | POST `/api/site/searchteam/Stats/queries/search/v2` `{text,limit,offset,sort_by:"count",sort_dir:"desc",period:"days_7"}` | запросы рынка: частота, заказы, GMV, продавцы, динамика |
| Аналитика (воронка) `/app/analytics?competitive=…` | composer-виджеты `salesFunnel*` | итоги наших продаж (есть в Seller API — не нужно) |
