Отчет по ограничениям API Озон и ВБ - что мешает и как мы это обошли (02.07.2026)

Платформа берет данные напрямую из Озон и ВБ. Но обе площадки в конце 2025 - начале 2026 сильно порезали свои API: часть данных убрали совсем, часть переехала на новые методы, а ВБ еще и жестко ограничил частоту запросов. Ниже все проблемы по-честному и что мы с каждой сделали.

ОЗОН

1. Озон убрал "цену покупателя" из API (12 ноября 2025).
Раньше Озон отдавал по API реальную цену, которую видит покупатель (со скидкой площадки). С 12 ноября это поле удалили. По API теперь доступна только цена продавца из кабинета - из-за акций она бывает в 1,5-2 раза выше реальной (пример: S2 по API 20 705 руб, а покупатель платит около 12 700 руб).
Что сделали: берем реальные цены из вашей таблицы "ДРР и цены". Там менеджер ведет и цену кабинета, и цену с СПП - они и показываются в разделах "Цены" и "Акции". Проверено, цифры сходятся с кабинетом.
Что осталось: третья цена ("зеленая" с Озон-картой, ~11 486 руб) - ее в таблице пока нет отдельной колонкой. Как только добавите колонку - подтянем автоматически.

2. Озон не отдает флаг "товар в акции".
Вместе с ценой покупателя Озон убрал и внятную информацию о том, участвует ли товар в акции площадки.
Что сделали: показываем процент СПП - насколько площадка снижает цену за свой счет. Высокий процент СПП фактически и означает "товар в акции". Это самый надежный признак из доступных.

3. Озон сменил методы по поставкам (11 декабря 2025).
Старые методы для заявок на поставку FBO отключили.
Что сделали: перешли на новые. Транзит на склады Озон (как вы просили - "в пути" плюс "на приемке", без черновиков) уже работает: сейчас видно 129 штук в дороге, включая POLFAR 84 шт - сходится с вашим кабинетом.

4. Финансовый отчет Озон приходит с задержкой 1-3 дня.
Это не поломка, а особенность Озона: свежие дни в финотчете неполные, данные "доезжают" пару дней. В "Финансах" это теперь подписано прямо на графике, чтобы не пугали "пустые" последние дни. Расхождение с "Культурой Аналитики" по той же причине - культура просто запаздывает, вы сами это отметили на созвоне.

5. Реклама Озон - отдельная система.
Рекламный кабинет Озон (Performance) - отдельный API со своими ключами, его расходы не попадают в обычный финансовый отчет.
Что сделали: подключили ключи Performance, расход и ДРР тянутся. Окно периода выровняли - раньше считалось 8 дней вместо 7, из-за этого расход казался завышенным (230 против ваших 217). После исправления просьба пересверить.

ВБ

6. Главная проблема - лимит запросов на весь кабинет.
ВБ ограничивает частоту запросов не для каждого сервиса отдельно, а на весь кабинет продавца сразу. Ваш кабинет опрашивают одновременно два сервиса: наша платформа и 10x (парсит раз в час). Лимит один на двоих - когда 10x его выедает, ВБ отвечает "слишком много запросов" всем, включая нас. Мы проверили с сервера напрямую: блок держится часами.
Из-за этого не работает: аналитика ВБ (воронка продаж) и детали поставок ВБ. Они пустые не из-за ошибки в коде - ВБ просто не пускает.
Что можно сделать: либо развести по времени (мы перенесем свой сбор на ночь, 4-6 утра, когда 10x скорее всего молчит), либо отключить/перенастроить 10x, если наша платформа его дублирует. Решение за вами - с нашей стороны код готов и ждет "окна".

7. ВБ массово отключил старые методы в конце 2025.
ВБ за полгода несколько раз менял правила (вы сами это отмечали): отчет по товарам отключен 9 декабря - перешли на новую "воронку продаж"; старый метод списка поставок на склад умер - нашли новый, код переписан; названия статусов поставок убрали 3 ноября, оставили только коды - расшифровали коды по живым данным.
Транзит на склады ВБ (как на Озон) готов и установлен: сейчас видно 7 поставок "в пути" на 4-12 июля. Количество штук по каждой подтянется, как только ВБ пустит по лимиту (см. пункт 6).

8. Отзывы: отвечать из платформы пока нельзя - токен "только чтение".
На созвоне при создании нового токена ВБ было выбрано "только чтение" ("вносить изменения нам не надо"). Читать отзывы мы можем и показываем их. Но чтобы отправлять ответы прямо из платформы, ВБ требует токен с правом записи на раздел "Вопросы и отзывы".
Что нужно: создать в кабинете ВБ еще один токен - "Вопросы и отзывы" с галочкой на запись - и передать нам. После этого кнопка "Ответить" заработает. По Озону ответы на отзывы позже, там своя механика.

9. Базовые токены ВБ отменяются.
ВБ объявил, что старые "базовые" токены перестанут работать (новость от 23 июня, вы ее присылали). Мы уже переехали на новый персональный токен, созданный на созвоне. Проверили все направления - токен живой везде: цены, продвижение, статистика, поставки, отзывы.

ИТОГО - что зависит от вас, три действия:
1) добавить в таблицу "ДРР и цены" колонку с третьей ценой (с Озон-картой);
2) создать токен ВБ "Вопросы и отзывы" с правом записи - чтобы отвечать на отзывы из платформы;
3) решить по 10x: развести тайминги или отключить, чтобы аналитика и поставки ВБ ожили.

Все остальное либо уже решено, либо решается на нашей стороне.
