# agent-host — хост сети агентов на ПК

Программа, которая живёт на домашнем ПК (позже — мини-ПК), забирает задания из
очереди дашборда e-avtovibe.ru и выполняет их через **обычный Google Chrome**
с домашнего IP. Сейчас поддержан сценарий `showcase_prices` — цена покупателя
по нашим товарам WB и Ozon.

Принципы (конституция проекта, не нарушать): никакого обхода антибота (без
прокси, headless и решения капч; при капче — стоп и пауза площадки), агент без
состояния (на ПК только код, `.env` и профиль Chrome), связь всегда инициирует
хост (polling), логины и пароли агент не вводит никогда.

## Установка (Windows, этап 1 — home-pc)

1. **Электропитание**: Параметры → Система → Питание — запретить сон при
   питании от сети; обновления Windows — активные часы на рабочее время.
2. Установить [Node.js 20+](https://nodejs.org) и [Git](https://git-scm.com), Chrome уже есть.
3. Клонировать репозиторий и поставить зависимости:
   ```
   git clone https://github.com/marketplace7000-afk/dashboard.git C:\agent\dashboard
   cd C:\agent\dashboard\agent-host
   npm install
   copy .env.example .env
   notepad .env        ← вписать AGENT_API_KEY (тот же, что на сервере)
   ```
4. **Профиль Chrome агента** (отдельный от личного!):
   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --user-data-dir=C:\agent\chrome-profile --remote-debugging-port=9222
   ```
   В открывшемся окне один раз вручную войти в покупательские аккаунты
   wildberries.ru и ozon.ru. Окно можно свернуть (не закрывать не обязательно —
   хост поднимет Chrome сам).
5. Проверка: `npm run check` — должен показать `Chrome: OK`, `Heartbeat: OK`,
   а в дашборде в разделе «Сборщики» появится хост `home-pc`.
6. Запуск: `npm start`. Для автозапуска — Планировщик заданий Windows:
   задача «AgentHost», триггер «При входе в систему», действие
   `C:\Program Files\nodejs\npx.cmd` с аргументами `tsx src/index.ts`,
   рабочая папка `C:\agent\dashboard\agent-host`; на вкладке «Параметры» —
   перезапуск при сбое каждые 5 минут. Плюс автологин Windows (`netplwiz`),
   чтобы после перезагрузки всё поднялось без человека.

## Настройка на сервере (однократно)

В `/opt/autovibe/.env` добавить `AGENT_API_KEY=<случайная строка ≥ 32 символов>`
(сгенерировать: `openssl rand -hex 24`) и перезапустить сервис. Тот же ключ —
в `.env` хоста.

## Перенос на другой ПК (этап 2 — mini-pc)

1. Повторить шаги 2–4 (или скопировать `C:\agent\chrome-profile` целиком — тогда
   входить в аккаунты заново не нужно).
2. Скопировать `.env`, поменять в нём `AGENT_NAME=mini-pc`.
3. `npm run check`; в панели убедиться, что `mini-pc` онлайн; `home-pc`
   поставить на паузу. Изменения в коде и базе не нужны (критерий ТЗ: ≤ 1 часа).

## Как это работает

Цикл: каждые `POLL_INTERVAL_SEC` — heartbeat → claim задания → выполнение с
отчётом о прогрессе (этапы видны в дашборде на экране «Сборщики») → complete /
fail. Темп: паузы 3–8 с между страницами, не более 120 страниц в час на
площадку (правится в панели). WB снимается батчами через card.wb.ru (2 запроса
на все товары), Ozon — проходом по витрине продавца и прямыми карточками.

При капче или блокировке хост немедленно останавливает задание, площадка
встаёт на паузу на 6 часов (видно в панели), повторов нет. Если истекла сессия
покупательского аккаунта — пауза «нужен вход»: откройте Chrome агента, войдите
и снимите паузу в панели.
