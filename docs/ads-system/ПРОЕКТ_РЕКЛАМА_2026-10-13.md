## Архитектура
Источники → **шлюз API** (очередь с лимитом на метод, приоритеты: действие > свежая статистика > история, учёт квоты,
ключи на сервере зашифрованы) → **хранилище фактов** (SQLite: реклама кампания×товар×день, кластеры, история ставок,
воронка по дням для всех товаров, снимки конкурентов) → **модели** (потолок ставки из маржи, узкое место воронки,
темп бюджета, эффект на органику) → **автопилот** и **агент роста** → интерфейс.

## Автопилот
- Цикл 30 мин: собрать → оценить → предложить → ограничители → применить/на подтверждение → замер через 24/72 ч → откат.
- Режимы: выключен / советует / с подтверждением (старт) / сам в пределах лимитов.
- Потолки: maxCPO = маржа × доля (40%); maxCPC = maxCPO × CR; maxCPM = maxCPC × CTR × 1000.
- Ограничители: шаг ±15%, не чаще раза в 2 ч на кампанию, остаток < 7 дн → снижать, < 3 дн → пауза,
  ДРР > 2× цели 3 дня → пауза, подмена органики → откат через 72 ч, резерв 20% квоты API, «Стоп всё».
- Рекламу не повышаем, если узкое место не в трафике (CTR, карточка→корзина, корзина→заказ, остаток) — создаём задачу команде.

## Этап 2 — автопилот-советник (14.10.2026)
- `api/_lib/ads/autopilot.ts`: после каждой РНП в цепочке сервера (и по кнопке «Пересчитать») строит предложения по
  обзору за 7 дней, хранит в `ad_proposal` (одно открытое на предмет; отклонённое молчит 3 дня, принятый совет — 7).
- Правила: пауза кампании (все товары «Не рекламировать» / остаток < 3 дн / 1 500 ₽ за 7 дн без заказов);
  дневной лимит WB для CPC без лимита (средний расход × 1,3); ставка −15% (остаток < 7 дн, расход ≥ 500 ₽ без заказов,
  ДРР > 2× нормы, площадка выше 5% и ДРР товара выше нормы, заказ дороже 40% маржи); +15% только при ДРР < 3%,
  ≥ 3 заказах, запасе ≥ 14 дн, марже ≥ 15%, площадка в бюджете и рост не пробьёт потолок маржи; узкое место в карточке/корзине
  → задача команде; Ozon без ручной ставки → недельный бюджет −15%; кандидаты на новую кампанию — совет.
  После любого изменения товар/кампания не трогаются 24 ч.
- API: `GET /api/ads2/autopilot?mp=&history=1`, `POST /api/ads2/autopilot` `{run}` | `{mode: off|confirm}` | `{id, decision, note, confirmBig}`.
  Применение идёт через actions.ts (actor = autopilot, причина «подтвердил менеджер»), перед этим сверяется, что ставка не изменилась.
- Экран «Автопилот»: режим, «Пересчитать», предложения (изменения / советы), «Решённые и замер» (3 дня до → до 3 дней после).
- Проверки: `scripts/check-ads-autopilot.ts` (22).

## Решения владельца (13.10.2026)
1. Бюджет рекламы = **5% от суммы заказов по цене продавца**, отдельно WB и Ozon (плавающий: месяц = 5% прогноза заказов,
   день = 5% от заказов вчера/среднего за 7 дн). Сейчас WB ≈ 7,5% (выше нормы), Ozon ≈ 3,3%.
2. Старт автопилота — «с подтверждением» 2 недели.
3. Новые кампании автопилот только предлагает, решает менеджер. Флаг товара «Не рекламировать» с причиной
   (самовыкуп, вывод, неактивна, другое) — такие товары автопилот игнорирует полностью.
4. Ozon — **Premium Plus**: полная `/v1/analytics/data`, `product-queries`; в кабинете 8 именных конкурентов,
   фильтры бренд/продавец и Excel в «Товарах на Ozon». Нет Pro: нет `category/comparison`, нет средней позиции конкурентов.

По умолчанию (не обсуждались): доля маржи под рекламу 40%, шаг ставки ±15%, роли владелец/менеджер.
