# План работ по итогам звонка с клиентом (ИП Алешко)

Источник: транскриб последнего звонка (прошлись по каждой странице/вкладке).
Главные сквозные запросы клиента:
1. **Свести все цифры** — они тянутся из разных мест, должны совпадать; убрать
   неверную маркировку.
2. **Починить доступ к аналитике ВБ** (429 «слишком много запросов»).
3. **Убрать лишнее**, навести порядок в модулях.
4. **Допилить парсер конкурентов** (ВБ + Ozon).

Статусы: ✅ сделано в коде (не задеплоено) · 🔧 осталось · 🧩 нужен вход клиента.
