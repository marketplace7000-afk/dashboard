# Auto Vibe

Кабинет аналитики для продавца на Wildberries и Ozon: продажи, цены и прибыль по товарам, себестоимость из таблицы клиента, реклама и ДРР, отзывы, финансовые отчеты, Telegram-бот.

React + Vite на фронте, Node 22 + Express на бэкенде (`server.ts` оборачивает `api/route.ts`). Все запросы к площадкам идут через серверный прокси с кэшем и очередями, браузер к WB и Ozon не ходит.

## С чего начать

Полная документация лежит в `docs/handover/`, читать по порядку начиная с `00_README.md`: обзор, архитектура, инфраструктура и доступы, интеграции, переменные окружения, деплой, хранилище, известные проблемы, история решений.

## Запуск локально

```bash
npm install
cp deploy/env.server.example .env   # заполнить ключи
npm run build
npm run serve                        # http://localhost:8080
```

Проверки перед выкаткой: `npm run check`. Выкатка на сервер описана в `docs/handover/06_деплой_и_эксплуатация.md`.
